# Berni Software Homebrew Tap

Free, open source Mac apps by [Berni Software](https://www.bernisoftware.com.br).

```sh
brew install --cask bernisoftware/tap/bawake
```

| Cask | App |
| --- | --- |
| `bawake` | [bAwake](https://bernisoftware.github.io/bawake/): see why your Mac won't sleep, and keep it awake while your AI agents and builds work. |
